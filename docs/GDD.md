## 1. 產品定位與核心體驗

一款「修煉養成 + 文字冒險」的瀏覽器 RPG。玩家扮演凡塵中一介無名之輩，從**奠基**踏起，一路遊歷天下、拜師習道、戰鬥歷練，直到叩問**三品神臨**的證道之途。核心體驗支柱：

1. **抉擇即角色**：文字事件的選項沒有絕對正解，而是塑造「赤心」（理想主義／現實主義光譜）與聲望陣營歸屬，直接影響結局文本。
2. **雙軸成長**：垂直軸是境界（奠基→…→外樓→神臨），橫向軸是天下輿圖遊歷（十三國＋太虛幻境＋兩處絕地）。
3. **可重玩性**：出身（13 選 1）× 道途（6 家，遊戲中習得而非開局選定）× 隨機事件池 × 分支主線 × 9 種結局模板，組合出不同的一輪遊玩（單輪約 30 分鐘以上）。
4. **原創主線**：《雪夜半珏》七章故事貫穿七個境界，於進入新境界時強制觸發，選擇會實質改變後續章節文本與終局尾聲段落。

## 2. 核心遊戲迴圈

```
建角（出身＋資質分配）
   └→ 奠基境界簡介 → 主線第 0 章（雪夜半珏）
        └→ 天下輿圖（點選節點旅行，每次移動消耗天數）
             ├→ 城鎮節點 → 進入 5×5 格狀內部地圖
             │     ├→ 集市（原本的城鎮敘事事件池）
             │     ├→ 店舖（花道元購買裝備）
             │     ├→ 修道院（首次：拜師選道途／之後：潛心修行小獎勵）
             │     ├→ 客棧（花時間回復元氣）
             │     └→ 街巷（純走位，小機率後巷遭遇戰）
             ├→ 太虛幻境 / 邊荒 / 隕仙林（特殊節點，直接觸發事件或戰鬥，邊荒／隕仙林另有機率戰鬥）
             └→ 太虛卷軸（懸賞任務看板，隨時可查看達成進度並領賞）
        └→ 道元累積達境界門檻 → 破境試煉（成功/失敗皆推進境界，只影響數值代價與文本，不卡關）
        └→ 進入新境界 → 觸發該境界對應的主線章節（若尚未觸發過）
        └→（重複遊歷／突破迴圈，直到抵達外樓境或達到行程上限）
   └→ 神臨境終極試煉 → 結局（依聲望陣營 × 赤心高低 × 試煉成功與否 × 主線抉擇 生成專屬結局文本＋回顧歷程）
```

## 3. 角色與屬性系統

### 3.1 建角流程（目前實作：2 步）
1. **選出身**（13 選 1，決定初始屬性加成、聲望加成、地圖起始位置）
2. **資質分配**（根骨/悟性/機緣/人脈，基礎 4 點 + 8 點自由分配，每項上限 9）

> 道途（六家）**不在建角流程**，而是遊戲中首次進入任一城鎮的「修道院」節點時觸發拜師事件習得，習得後才開始解鎖對應技能。

### 3.2 四維屬性
| 屬性 | 主要影響 |
|---|---|
| 根骨 gu | 戰鬥防禦/氣血上限、部分突破判定 |
| 悟性 wu | 戰鬥暴擊率、部分突破判定、事件選項 |
| 機緣 ji | 隨機好結果機率、部分突破判定 |
| 人脈 ren | 社交類事件選項、聲望增長 |

### 3.3 資源與聲望
- **道元**：核心貨幣，用於突破消耗、購買裝備、施展技能（戰鬥中）
- **赤心**（0–100）：理想主義／現實主義光譜，決定終局文本基調
- **元氣**（0–100）：健康值，歸零觸發早夭結局
- **年齡 / 天數**：世界地圖旅行消耗 30–55 天／次；城鎮內每步消耗 1 天；滿 360 天年齡 +1（起始 16 歲）
- **四類聲望**：廟堂 / 江湖 / 道統 / 邪道好感，決定終局結局傾向

### 3.4 出身（13 選 1）
六雄：景國、齊國、楚國、秦國、荊國、牧國
附庸／列國（7）：莊國（寒門均衡型，起點劇情觸發地）、曲國（依附齊國）、越國（依附楚國）、雲國（獨立列國）、黎國（西北新興）、中山國（依附景國）、宋國（依附楚國）

各出身皆有專屬 `attr` 屬性加成 ＋ `fame` 聲望加成 ＋ 簡述文字，詳見設定文件。

### 3.5 道途（六家，遊戲中習得）
道家、儒家、墨家、法家、兵家、商家。各自有屬性加成、聲望傾向，並解鎖 3 個戰鬥技能（依境界 stageIdx 1／3／5 解鎖），耗道元施展。

## 4. 修行境界系統

7 個境界（`CULT_STAGES`，index 0–6）＋ 終極試煉「神臨境」：

| index | 品階 | 名稱 | 突破判定屬性 |
|---|---|---|---|
| 0 | — | 奠基 | 根骨 |
| 1 | 九品 | 游脈境 | 悟性 |
| 2 | 八品 | 周天境 | 悟性 |
| 3 | 七品 | 通天境 | 根骨 |
| 4 | 六品 | 騰龍境 | 根骨 |
| 5 | 五品 | 內府境 | 悟性 |
| 6 | 四品 | 外樓境 | 綜合四維平均 |
| 終 | 三品 | 神臨境（終局試煉） | 綜合（四維+道元+聲望） |

- 各境界道元門檻遞增：`STAGE_THRESHOLD = [25,45,65,85,105,130,155]`
- 突破永遠會推進境界（fail-forward 設計）：成功消耗 50% 道元、扣元氣；失敗消耗 30% 道元、扣更多元氣，但**不會卡關**
- 每進入一個新境界，若該境界有對應主線章節且尚未觸發過，會強制優先顯示（見第 8 節）

## 5. 天下輿圖與城鎮系統

### 5.1 世界地圖（`MAP_NODES`，共 16 節點）
- **城鎮型**（13）：六雄 + 7 附庸列國，皆可進入格狀內部地圖
- **特殊型**（3）：太虛幻境（無戰鬥、無格狀地圖，直接事件池）、邊荒（gate: stageIdx≥4）、隕仙林（gate: stageIdx≥5，兩者皆為高風險戰鬥區）
- 節點以水墨風格 SVG 呈現：印章式圓形節點＋專屬字符、五域背景大字水印、曲線驛道、指北針裝飾
- 移動一次消耗 30–55 天（隨機），非城鎮的危險節點有機率觸發戰鬥（一般節點 0%／危險節點 45%）

### 5.2 城鎮內部地圖（5×5 格狀，`TOWN_POIS`）
固定版型（所有城鎮共用同一格局，僅集市內容依城鎮不同）：
| POI | 座標 | 功能 |
|---|---|---|
| 城門 | (2,4) | 入口／隨時可退出返回世界地圖 |
| 店舖 | (0,1) | 隨機提供 3 件商品購買 |
| 修道院 | (4,1) | 拜師習道／潛心修行 |
| 客棧 | (1,2) | 投宿回復元氣（耗時 3 天） |
| 集市 | (3,0) | 觸發該城鎮的敘事事件池 |
| 其餘 20 格 | — | 純街巷，走一步耗時 1 天，8% 機率觸發一般難度後巷遭遇戰，40% 機率出現環境氛圍小文字 |

僅能移動到當前位置上下左右相鄰格（`is-adjacent` 判定），點擊即移動。

## 6. 事件與內容池

- **城鎮事件**：六雄城鎮各自擁有 3 則專屬敘事事件（含分支選項），7 個附庸列國共用一組 4 則「列國境遇」事件池
- **特殊節點事件**：太虛幻境（4 則）、邊荒（3 則）、隕仙林（3 則）
- **通用填充事件**（`FILLER_EVENTS`）：4 則低風險小品，當節點事件池抽完後接手，避免重複造訪時無內容
- 每則事件固定 3 個選項，各自標註主導屬性（〔根骨〕〔悟性〕〔機緣〕〔人脈〕〔赤心〕〔廟堂〕〔江湖〕〔道統〕等），附帶效果與結果敘述文字

## 7. 戰鬥系統

- **形式**：回合制選單戰鬥（攻擊／技能／逃跑），雙方剪影對戰畫面
- **觸發時機**：世界地圖旅行至危險節點（45%）、城鎮街巷走位（8%）
- **視覺**：雙方各以水墨線條剪影呈現，**玩家剪影依實際裝備變化**（防具顏色依品級、持有武器繪出對應色澤兵刃、飾品呈現頸部光點），敵人依類型／強度呈現顏色與是否帶靈壓光暈（精英敵人）
- **數值公式**：
  - 攻擊 = 4 + 根骨×1.2 + 悟性×0.6 (+裝備)
  - 防禦 = 2 + 根骨×1.0 (+裝備)
  - 速度 = 4 + 悟性×0.6 + 機緣×0.6 (+裝備)
  - 暴擊% = 5 + 機緣×1.2 (+裝備)
  - 氣血上限 = 60 + 根骨×7 + 境界×12 (+裝備)
  - 傷害 = max(1, 攻擊−防禦×0.5) ± 隨機浮動，暴擊 ×1.6
  - 閃避率 = clamp((我方速度−敵方速度)×1.5+6, 3, 30)
- **動畫效果**：浮動傷害數字（一般／會心／回復／閃避不同顏色與字級）、受擊震動、頭像高光，回合間有「回合結算中……」節奏停頓（尊重 `prefers-reduced-motion`）
- **敵人分兩檔**：一般（剪徑毛賊／野狼群／宵小術士）、精英（邊荒游魔／石像守衛／修羅武士，僅出現於危險節點，掉落品質更高）
- **戰鬥結算**：勝利獲得道元＋機率掉落裝備；落敗扣元氣、不會直接死亡（除非元氣已見底）

## 8. 裝備 / 技能 / 任務 / 主線系統

### 8.1 裝備（`ITEMS`，12 件）
三槽位（武器／防具／飾品）× 四品級（丁／丙／乙／甲，對應世界觀的法門品級用語），品級越高加成越大。取得管道：戰鬥掉落、店舖購買（丁 15／丙 35／乙 70／甲 140 道元）。

### 8.2 技能（`PATH_SKILLS`，6 道途 × 3 招 = 18 招）
依境界解鎖（stageIdx 1／3／5），戰鬥中耗道元施展，類型涵蓋攻擊／治療／增益／削弱。

### 8.3 太虛卷軸任務（`QUESTS`，8 項）
跨系統整合的懸賞任務（突破境界、拜師、遊歷城鎮數、戰鬥勝場、絕地建功、裝備蒐集、赤心值），達成後手動領取一次性獎勵，隨時可從地圖／城鎮畫面查看。

### 8.4 主線劇情《雪夜半珏》（`MAIN_STORY`，7 章）
- 對應 7 個境界，進入新境界時**強制優先觸發**（早於自由遊歷）
- 核心：少年顧懷安、半枚玉珏、無生教陰謀
- 分支關鍵狀態（存於 `state.story`）：`savedHuaian`（奠基章是否救人）、`alliedHuaian`（是否與顧懷安結盟）、`artifactFate`（destroyed／handed／kept，外樓章決定玉珏去向）
- 分支影響：第 2、3、6 章開場文本依 `savedHuaian`／`alliedHuaian` 動態切換；終局統一附加「主線尾聲」段落（`buildStoryEpilogue`）

## 9. 結局系統

`buildEnding(state)` 依序判斷：
1. 元氣 ≤ 0 → 早夭結局（不論其他條件）
2. 四類聲望取最高者（廟堂／江湖／道統／邪道）決定結局大方向
3. 邪道最高且 ≥25 → 墮入魔道分支
4. 道統最高＋赤心≥70＋神臨成功 → 稀有「太虛真人」彩蛋結局（隱含與原作主角擦肩而過的致敬彩蛋）
5. 其餘依聲望×赤心高低×神臨成功與否，共 9 套結局模板，動態代入實際抵達的最高境界名稱
6. 主線尾聲段落一律附加在結局正文之後

## 10. 技術架構

- **單一 HTML 檔**：CSS 內嵌（含明暗主題 token 化設計）、JS 以立即執行函式包裹，無外部依賴、無建置流程
- **狀態管理**：`state`（角色資料）、`flow`（遊戲進度：境界/行程/地圖位置）、`combat`（戰鬥中暫存，非戰鬥時為 null）三個模組層級變數，畫面渲染皆為命令式 `render*()` 函式直接操作 DOM
- **主題**：CSS variable token 系統，支援 system/light/dark 三態（`prefers-color-scheme` + `data-theme` 屬性雙軌）
- **部署**：
  - GitHub Pages：`chixin-lu` repo 的 `index.html`，push 後 1–2 分鐘生效
  - Claude Artifact：獨立發布，需另外用 Artifact 工具同步（兩處目前**不會自動同步**，每次改版需手動各推一次）
- **本機測試方式**：`.claude/launch.json` 設定 `python3 -m http.server` 起本地伺服器，用瀏覽器 MCP 工具連線測試（因為此環境的 `file://` 直接開啟為靜態快照、無法互動）
