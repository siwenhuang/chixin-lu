## 1. 作品基調與核心精神

《赤心巡天》整體基調是**理想主義包裹在殘酷現實之中**：超凡世界弱肉強食、階級森嚴（「超凡的世道，普通人是沒有未來的」），但主角一系人物始終堅持「把自己當人看，也把別人當人看的赤子之心」（2-27）。核心語彙反覆圍繞：

- **選擇與擔當**：「人是由他的選擇所決定的」（1-11）；「超凡兩字的份量，不是權勢、地位，而是沉重的職守與承擔」。
- **微光敘事**：「你看到了光，那就是光。你閉上了眼睛，那就是暗」（3-150）——世界殘酷但總有人堅守良善，不做非黑即白的簡化道德判斷。
- **凡人與超凡的鴻溝**：修士與凡人之間存在難以跨越的力量鴻溝，但作品反覆強調「人不以天賦定終生」（開脈丹的核心口號），弱者的尊嚴與抗爭是重要母題。
- **家國與江湖並重**：既有廟堂權謀、列國爭霸的「官道」敘事，也有宗門修行、江湖恩怨的傳統仙俠元素，兩者透過「官道」「國勢」「人氣」等設定緊密綁定。
- 文風上古典厚重，大量化用《莊子》《老子》《楚辭》等典故與擬古詩詞，各家顯學（儒釋道法兵墨等）皆有專屬的價值觀短句（如儒家「取信、德、仁、殺」），構成整部小說的思想骨架。

## 2. 修行/力量體系

### 2.1 主流「道術」修行境界（由低至高）

境界劃分稱「品」，共九品到一品，一品之上為跳脫品階的「超品」。每一境界皆有其核心概念與突破標誌：

| 品階 | 境界名稱 | 核心概念 |
|---|---|---|
| （入品前） | **【奠基】** | 入九品前的體魄調養階段，積累道元但無法發揮超凡戰力，非越早越好 |
| 九品 | **游脈境** | 超凡之始。道脈初顯連通全身，沖脈生成道元，以神念布列陣點形成「道旋」 |
| 八品 | **周天境** | 通天宮內構建三重「道旋」，即「小周天」，三重小周天合成「大周天」 |
| 七品 | **通天境** | 人身四海之首「脊柱海」（即通天宮）徹底甦醒，鑿穿「天地門」（蒙昧屏障） |
| 六品 | **騰龍境** | 突破天地門，肉身可飛行；軀幹海（五府海）蒙昧之霧初清，「天地孤島」鎮壓其上 |
| 五品 | **內府境**（古稱「神通境」） | 開發五府中的「內府」與「秘藏」，可能孕育「神通種子」，是神通誕生的關鍵境界 |
| 四品 | **外樓境** | 構築「星穹聖樓」，錨定星域、接引星光，形成「道途」；神通若已具備可煉出「神通靈相」 |
| 三品 | **神臨境**（古稱「不朽境」，屬「上三品」之始） | 金軀玉髓、身魂得天地認可，不再受氣血衰朽所限，壽達 518 歲；突破時外放「域」（小世界雛形）與「靈識」 |
| 二品 | **洞真境** | 貫通四海、以靈煉神，把握「真世」與「道則」；壽達 1296 歲；「真人」開始具備「真言」等撼動規則之力 |
| 一品 | **衍道境**（即「真君」） | 法身合道身，念動即定規則，「我思故我在，我意即天意」；壽元未明 |
| 超品 | **超脫境** | 跳脫九品認知之外，無法定義的境界，「超脫無古今」，證道之路人人不同，「阻道」風險極高 |

其他重要子概念：
- **道脈 / 道元 / 道旋 / 神魂 / 道脈真靈**：道脈是超凡根基，脊柱如「人體大龍」；道元是修士修行本源；道旋是九品標誌；神魂是精神/識感層次；道脈真靈是修者超凡本質的具體化，隨境界成長蛻變。
- **人身四海**：脊柱海（通天宮）、軀幹海（五府海/內府所在）、四肢海（藏星海）、頭部海（元神海/蘊神殿）——分別對應通天、內府、外樓、神臨（上三品）四大修行階段。
- **神通**：神通種子（五品秘藏）成熟後的完整力量形式，是修士「道途」的重要依據，關乎修行未來上限。
- **法相 / 法身 / 道身（道軀）/ 道質**：真君級以上的力量具現形式，法身出竅合界、行走治世但有被覷破道則的風險；道質是絕巔標誌。

### 2.2 境界之外的「力量分流」

除主流道術體系外，設定中平行存在多條修行路線，均可視為獨立的「職業體系」：

- **武道**：脫胎自兵墨，純以體魄與氣血修行、不蓄道元，境界不分九品而以「**重天**」計（每三重天一境，理論存在第 33 重天的超脫至境）。
- **兵家**：以兵勢入道，取「勢、烈、御、殺」，天下兵家必爭之地，自古無聖地。
- **商道**：取「信、烈、容、利」，修煉「氣運」與財富。
- **官道**：修士為官即闡道，融合法儒兵墨，離不開「人氣」，「以權勢促公益則興，以權勢謀私利則亡」。
- **道家 / 釋家 / 儒家 / 法家 / 墨家 / 醫家 / 陰陽家 / 名家 / 農家 / 雜家**：即「諸子百家」，各家皆有專屬「道途」取向（如道家取「威誠仁殺」、墨家取「威潔容武」、法家取「威烈正刑」、儒家取「信德仁殺」），修行成就與所信奉的思想理念強掛鉤。
- **命途（卦師/命占/血占/星占）**：以命理、卜算為修行依據，星占是現今卜術主流。
- **仙術**：近古仙宮時代的獨有「術介」體系，威能強於一般道術但傳承條件嚴苛。
- **神道**：由不甘轉世的鬼魂修煉而來，依附信仰香火，天獄妖族世界曾是神道鼎盛之地。
- **器修 / 飛劍 / 陣道 / 咒道 / 馭獸**：偏門或式微的分支修行方式，各有其興衰史。

### 2.3 突破機制關鍵詞

- **開脈丹**：解決天賦不足問題的「人族不以天賦定終生」核心道具，依成色分人品（甲乙丙丁）、地品、天品，直接掛勾國家的凶獸畜養與資源政策。
- **法門品級**：現世術秩以四等十二品（甲乙丙丁，各分上中下）劃分至神臨為止；超越此列稱「天地玄黃」四階，天地兩階更逼近真君層次。
- **道曆紀年**與各國自有年號並行使用（詳見第 7 節）。

## 3. 世界結構與地理

### 3.1 天下大勢

現世（主體世界）以中域為核心，劃分**東域、西域、南域、北域、中域**五大方位，另有現世之外的多重「異界/秘境/絕地」。天下公認最強的六大國家稱「**天下六雄**」：

| 國家 | 所處方位 | 定位 |
|---|---|---|
| **景國** | 中域 | 現世至強、最古老的享國者，道屬三聖（玉京山、大羅山、蓬萊島）共治色彩濃厚，都城天京 |
| **齊國** | 東域 | 東域霸主，商貿昌盛、附庸國眾多，都城臨淄 |
| **楚國** | 南域 | 「唯楚術甲天下」，世家政治盛行，都城郢都 |
| **秦國** | 西境 | 「赳赳老秦」，尚黑重法，鎮守虞淵防線（萬里長城） |
| **荊國** | 北域 | 唯一高度軍事化的「軍庭帝國」，首領合議制，都城計都 |
| **牧國** | 北域 | 唯一政教合一、信奉神道（蒼圖神教）的霸主國，與荊國共守北域 |

六雄之外「列國」至少一百三十六數，其中主角故事起點所在的**莊國**（西境道屬國）並非六雄之列，但為故事早期核心舞台。

### 3.2 主要國家清單（依方位摘錄，非全部）

- **中域**：景國、佑國、沃國、季國、中山國、隋國（已併入景國）
- **東域**：齊國、暘國（已滅，分裂出「日出九國」：陽、明、昭、昌等）、曲國、鄭國、容國、晉國、樂國、申國、弋國、旭國、燕國（已滅）、韶國（已滅）
- **南域**：楚國、夏國（已滅，後有梁國復辟其一隅）、越國、魏國、宋國、理國、南陳（已滅）
- **西域**：雲國、陌國、宛國、洛國、雍國、成國、礁國、陳國、和國、丹國、喬國、宣國、芮國、莊國
- **北域 / 西北**：荊國、牧國、黎國（前身「雪國」，統合西北五國：高、鐵、寒、契遼、真等）

### 3.3 特殊地理 / 異界秘境

- **太虛幻境**：太虛派主導、聯合多方勢力構建的「修練虛擬空間」（籠入心神的太陰星力產物），內建「功/法」雙貨幣、論劍台（PVP 排位）、福地挑戰（賽季奪城）、演道台（技能推演升級）、太虛角樓、鴻蒙空間、太虛卷軸（懸賞任務）等完整制度，堪稱世界觀內建的「遊戲中的遊戲」。
- **萬妖之門**：人妖分界的核心地標，需天下六雄至少三國同意方可變動其狀態；門後五座「副門」設於各霸國境內。
- **天獄**（妖界，妖族稱「新界」）：緊鄰現世最大混沌世界，妖族被逐後的棲息地，內含文明盆地、霜風谷、萬神海、封神台等地標。
- **滄海 / 迷界**：滄海是海族領地、當世五大凶險地區之一；迷界是滄海與近海間的「空無區域」，人族與海族主戰場，規則破碎、「不成外樓不出海」。
- **邊荒 / 虞淵**：邊荒是極北荒漠，魔潮與魔族發源地；虞淵是西極「不可回歸之地」，修羅族巢穴，與秦國的萬里長城防線直接對抗。
- **禍水（孽海）**：南域「惡念叢生」的危險地帶，佛稱「無根」，道稱「孽海」，設有「蓮子」氣泡世界供修行避難／傳道。
- **隕仙林 / 兵墟**：南域盡頭的現世至凶之地，聖者殞落、仙宮破滅之所；兵墟為兵仙宮遺址。
- **九大仙宮遺址**：近古仙宮時代遺留（萬仙宮、兵仙宮、雲頂仙宮等），多已成廢墟秘境（如遲雲山、天府秘境、七星樓秘境、山海境、神霄），皆採「限時開放、高風險高回報」機制。
- **浮陸世界 / 森海源界**：現世之外的獨立小世界，各自有專屬力量體系（浮陸的「圖騰體系」、森海源界的神/龍神信仰），可視為平行宇宙支線舞台。
- **幽冥 / 源海**：死後歸宿體系，源海是萬物本源的最終歸宿（「一」）。

## 4. 勢力與陣營

### 4.1 政治／宗教三大支柱

1. **道屬體系**：以「道門三聖」——**玉京山**（重儀軌、講牌面）、**大羅山**、**蓬萊島**（海外隱世聖地）——為核心，以「屬而不統」方式扶植多個「道屬國」（如盛國、莊國），構成半宗教半政治的跨國聯盟。
2. **儒門書院**：四大書院——**暮鼓書院**（南域，儒祖嫡傳）、**龍門書院**（南域，書劍第一）、**青崖書院**（中域，長於辯經）、**勤苦書院**（西境，以苦學聞名）——並稱天下儒學正統，另有「天下第五書院」爭議名額（浩然書院等）。
3. **佛門**：**懸空寺**（東域，佛門東聖地）、**須彌山**（雲楚之間，西聖地）為兩大並立聖地，另有已遭滅門的**枯榮院**（齊國）、隱世的**洗月庵**（衛國）等。

### 4.2 邪道與異端勢力

- **白骨道**：祭祀「白骨尊神」的邪教，教義「死亡是唯一的公平」，以「道子」「聖女」為核心道果，是早期故事的主要反派勢力。
- **無生教**：白骨道殘餘骨幹另立的新興邪教，發展迅速。

### 4.3 太虛閣與主角所屬組織

**太虛閣**：太虛幻境衍生出的精英巡察組織，成員稱「太虛巡察使」，是主角姜望及其同輩天驕（李一、蒼瞑、鬥昭、重玄遵、黃舍利、秦至臻等）的核心身分歸屬，具跨國、超脫國家立場的特殊地位。

### 4.4 世家與門派

各國內部另有龐雜的世家政治生態（如齊國石門李氏、秋陽重玄氏、貝郡晏氏、南遙廉氏；景國姬姓皇族及玉京/大羅/蓬萊三系府縣共治），以及獨立宗門（劍閣、血河宗、青雲亭、南斗殿、五仙門、東王谷、仁心館等），彼此間常見「勢同水火」的世仇（如齊國田氏 vs. 柳氏）與利益結盟。這種「國家 — 道屬教門 — 儒佛顯學 — 世家宗門」四層交織的權力結構，是本作政治敘事的骨幹。

### 4.5 種族陣營

- **人族**：現世統治者，本為妖族「以妖為模板」創造的勞動附庸種族，「人生來不潔、天生原罪」是重要設定梗。
- **妖族**：遠古天下統治者，被逐居天獄，實力分級「小妖→妖兵→妖將→妖帥→妖王→真妖→天妖」。
- **水族 / 海族 / 龍族**：同源分化。水族友善依附人族；海族是中古水族分裂後追隨龍皇退居滄海的一支，舉族皆兵；龍族血脈最尊貴，中古大戰後已與人族疏遠、近乎絕跡。
- **修羅**：虞淵原生種族，男修羅女羅剎，好戰嗜殺、單胎產一，與人族長年鏖戰。
- **魔族**：邊荒原生，分陰魔、將魔、真魔、天魔、魔君等層級，另有源自失敗魔功修煉者的「六欲之魔」「七情之魔」等變體。
- **靈族**：妖族創造的融合種族（人身、魔氣經絡、妖徵、神嬰四合一）。
- **百族**：遠古其餘弱勢種族統稱（水族、火族、風族、石族等），上古大戰後多滅絕或融入人群。

## 5. 關鍵超自然概念

| 詞條 | 概念解釋 |
|---|---|
| **道元** | 超凡之本，意與力融合而成，修士修行的能量貨幣 |
| **道脈 / 道脈真靈** | 超凡根基與其本質具現化，隨境界成長蛻變 |
| **神魂 / 靈識 / 元神** | 精神力量的三個層次：神魂（識感統合）、靈識（神臨後具體干涉現實的力量）、元神（神魂徹底顯化之身） |
| **神通** | 由五品「神通種子」孕育而成的完整力量形態，是修士修行特質與未來上限的關鍵指標 |
| **域 / 真世 / 小世界** | 神臨突破時外放的力量異象，逐步演化為個人專屬的規則空間（小世界雛形） |
| **道則 / 道質** | 真人以上洞悉、掌握的世界規則；道質是絕巔（超脫前夜）的具體標誌 |
| **法寶（洞天之寶）** | 倚傍「洞天」之力煉成的至寶，不受規則侵害但有損耗與折舊，性質介於法器與仙宮之間 |
| **開脈丹** | 打破天賦壁壘、普及超凡修行的關鍵丹藥，衍生出各國「獸巢畜養凶獸」的資源政治 |
| **命格 / 神階 / 神格** | 神道體系的核心概念：命格是出生時獲世界規則認可的身分；神格依修為分假神、真神、陽神、神祇 |
| **金軀玉髓** | 神臨境標誌，肉身純煉出神性、突破氣血衰朽大限，但壽盡前損毀代價極大 |

## 6. 重要人物（身分輪廓，避免劇透）

### 主角
- **姜望**：楓林鎮藥鋪出身的貧家子弟，太虛化名「獨孤無敵」，佩名器【長相思】。故事沿其開脈、入品、突破至衍道境的成長線展開，官途上曾任齊國「武安侯」，修行上是太虛閣首位入閣真人，人稱「鎮河真君」。核心神通包括【三昧真火】【赤心】【劍仙人】【不周風】【歧途】等。

### 至親
- **姜安安**：姜望幼妹，凌霄閣（雲國）游脈境修士，與主角情感線是全書重要的情感錨點。

### 太虛閣同輩天驕（並列群像）
李一（道劍宗師，根本劍道「一」）、蒼瞑（牧國，現世神使）、鬥昭（楚國「世之天驕」，鬥戰七式）、重玄遵（齊國冠軍侯）、黃舍利（荊國，黃弗愛女）、秦至臻（秦國，拳道大家）——皆與姜望同列太虛巡察使，構成主角的「同代天驕群像」。

### 摯友與盟友
- **重玄勝**：齊國秋陽重玄氏家主，姜望至交，商略與家業並重的複雜人物。
- **晏撫**：貝郡晏氏，前相國晏平嫡孫，姜望、李龍川的少年好友。
- **李龍川**：石門李氏俊彥，逐風軍正將，弓道高手。
- **白玉瑕**：越國世家出身，白玉京少東家。

### 各國統治核心（背景設定角色）
齊國姜氏皇室（姜述、太子姜無華等）、景國姬姓皇室、楚國熊氏皇族與「星巫」諸葛義先、秦國嬴姓皇室、牧國赫連氏、莊國莊姓王室等，構成列國博弈的權力頂端。

### 主要對立/神秘勢力代表
- **白骨尊神**：白骨道信仰核心，幽冥神祇，早期故事的重要邪道威脅。
- **凰唯真 / 凰今默**：楚國「山海境」秘境創造者及其女，牽動楚國政局的神秘存在。

## 7. 時間線骨架

大時代依序為：**遠古（蒙昧）→ 上古 → 中古 → 近古 → 新啟（現行道曆紀元）**。

| 時代 | 概況 |
|---|---|
| **遠古（蒙昧期）** | 妖族／龍族統治天下；人皇燧人氏崛起，創建氣血沖脈、道門，開闢人族超凡之路；末期人皇聯合百族大戰妖族，妖族敗走天獄 |
| **上古** | 妖族反攻，人族建成「萬妖之門」封鎖；魔潮爆發並最終終結；世尊誕生 |
| **中古** | 世尊、墨祖相繼超脫；水族分裂（一支追隨龍皇退居滄海成為海族）；烈山氏將龍皇逐於滄海，龍族自此絕跡於世；人族與水族締結盟約 |
| **近古** | 依序歷經「諸聖時代」（三萬七千年，百家聖人輩出，蓮華聖界計畫、大成至聖計畫）、「神話時代」、「仙宮時代」（九大仙宮興起又神秘覆滅）、「一真時代」（牧國蒼圖信仰肇建，《昊天高上末劫之盟》簽立，超脫者自此避世不再干涉現世） |
| **新啟（道曆紀元，現行紀年）** | 道曆元年景國建立、天京落成，其後齊、楚、秦、荊、牧等列國相繼立國或崛起，形成「天下六雄」格局 |

### 故事主線關鍵年表（道曆）
- **3865年**：齊國姜述即位，年號元鳳。
- **3888年**：齊夏爭霸大戰爆發，齊國崛起為東域霸主的關鍵戰役。
- **3897年**：首屆黃河之會（列國天驕競技盛會）舉行。
- **3900年正月廿八**：主角姜望出生於莊國楓林鎮。
- **3917年**：姜望開脈、入游脈境，故事正式展開（第一卷起點）。
- **3918年**：齊國靖陽之戰，收復陽國三郡。
- **3921年**：齊夏國戰，夏國滅亡；牧國「萬教合流」神道新制頒布。
- **3923年**：姜望洞真；太虛角樓相關制度擴張。
- **3926年**：雪國改號「黎國」，統合西北五國聯盟。
- **3929年**：姜望衍道；景國「靖海計畫」失敗，敖舒意身死。
- **3930年代（現行連載進度，至第 15–16 卷）**：黃河之會等大型跨國事件持續推進，並預告「神霄戰爭」（3955年）等未來大戰伏筆。

## 8. 遊戲設計可用素材筆記

1. **境界＋子概念的清晰分層，天生適合等級/科技樹系統**：九品到衍道共十級，每級都有明確的「解鎖標誌」（道旋、天地門、內府秘藏、星穹聖樓、域、真世、法身……），可直接映射為 RPG 的等級節點或天賦樹分支，甚至用「奠基」設計為角色創建前的資質分配階段。

2. **五行＋擴充屬性的道術分類，適合技能/卡牌收集系統**：金木水火土外加風、光、雷、霜等行屬，疊加甲乙丙丁四等十二品的品級制，天然形成「屬性 × 稀有度」矩陣，可做成卡牌抽取、技能合成或裝備熔煉系統的底層邏輯。

3. **太虛幻境本身就是現成的「遊戲化副本」框架**：功／法雙貨幣、論劍台匹配戰（PVP 排位）、福地挑戰（賽季爭霸城池）、演道台（用資源换技能升級）、太虛榮名（賽季稱號）——這套設定幾乎可以原樣移植為手遊的競技場/公會戰/賽季系統，無需大改。

4. **天下六雄＋百家顯學的雙軸陣營系統，適合「國家陣營 × 職業流派」的雙重養成**：玩家可選擇效忠六大國家（景/齊/楚/秦/荊/牧，各自風格鮮明：法治、商貿、繁華、軍國、鐵血、神權），同時再選擇諸子百家中的一派（儒/墨/道/法/兵/商/官/釋/醫/陰陽/名/農/雜），每派皆有官方寫定的「道途取向關鍵字」（如法家「威烈正刑」），可直接轉譯為職業技能樹的核心屬性標籤。

5. **多重異界秘境的「限時高風險副本」設計已經內建**：天府秘境（十二年一開、僅存活率極低）、七星樓秘境（星力週期開放）、遲雲山（三十三年一開）、山海境（玉璧信物限量入場）皆遵循「稀缺開放窗口＋高獎勵＋高折損率」的統一邏輯，可直接對應手遊限時 Raid / 輪替副本活動，並用「入場信物」機制自然帶出付費道具或稀有材料的獲取途徑。
